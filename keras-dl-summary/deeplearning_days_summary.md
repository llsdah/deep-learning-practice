# 딥러닝 핵심 개념 정리

---

## 1장. 학습 기초 개념

### 1.1 학습 단위와 하이퍼파라미터

딥러닝 모델을 학습시키기 위해서는 학습 과정을 제어하는 여러 하이퍼파라미터를 이해해야 한다.

**에포크(Epoch)**  
전체 학습 데이터를 한 번 모두 훑는 횟수를 의미한다. 예를 들어 10 epoch이면 전체 데이터를 10번 반복 학습한다.

**배치 크기(Batch Size)**  
전체 데이터를 한 번에 처리하지 않고 작은 묶음 단위로 나누어 기울기를 계산하고 가중치를 업데이트하는 단위이다. 배치 크기가 크면 학습이 안정적이지만 메모리 사용량이 늘어나고, 작으면 노이즈가 많지만 일반화 성능에 유리한 경향이 있다.

**학습률(Learning Rate)**  
역전파로 계산된 기울기(Gradient) 방향으로 가중치를 얼마나 크게 이동할지를 결정하는 하이퍼파라미터로, 손실 함수의 최솟값을 찾아가는 **보폭**에 해당한다.

- 학습률이 **너무 크면** 최적점을 지나쳐 발산(Overshooting)한다.
- 학습률이 **너무 작으면** 학습 속도가 정체되거나 지역 최솟값(Local Minimum)에 갇힐 위험이 있다.
- 일반적으로 0.1 ~ 0.0001 범위에서 설정하며, Learning Rate Scheduler로 점진적으로 줄이기도 한다.

**모멘텀(Momentum)**  
이전 기울기의 방향을 현재 업데이트에 관성처럼 반영하는 값이다. 학습률과 함께 사용되어 수렴 속도를 높이는 역할을 한다.

---

### 1.2 활성화 함수 (Activation Function)

활성화 함수는 신경망의 각 뉴런이 입력을 받아 출력으로 변환할 때 적용하는 비선형 함수이다. 비선형성이 없으면 아무리 층을 깊게 쌓아도 선형 모델과 동일하기 때문에 필수적이다.

| 함수 | 출력 범위 | 특징 | 주요 사용처 |
|------|----------|------|------------|
| 시그모이드(Sigmoid) | 0 ~ 1 | 깊은 층에서 기울기 소실 문제 발생 | 이진 분류 출력층 |
| 하이퍼볼릭 탄젠트(Tanh) | -1 ~ 1 | 시그모이드보다 기울기 소실이 덜함 | 은닉층 |
| ReLU | 0 ~ ∞ | 계산 단순, 기울기 소실 완화. Dying ReLU 문제 존재 | 은닉층 (현재 표준) |
| 소프트맥스(Softmax) | 0 ~ 1 (합=1) | 여러 출력값을 확률로 변환 | 다중 클래스 분류 출력층 |

> **ReLU**는 \`f(x) = max(0, x)\`로 정의되며, 0 이하 입력은 0을 출력하고 0 초과 입력은 그대로 출력한다. 현재 딥러닝 은닉층의 표준 활성화 함수이다.

---

### 1.3 순전파와 역전파

**순전파(Forward Propagation)**  
입력 데이터가 입력층 → 은닉층 → 출력층 방향으로 통과하며 예측값을 계산하는 과정이다.

**역전파(Backpropagation)**  
출력층에서 계산된 오차(손실)를 출력층 → 은닉층 → 입력층 방향으로 거꾸로 전달하면서, 연쇄 법칙(Chain Rule)을 이용해 각 가중치가 손실에 기여한 정도(기울기)를 계산한다. 이 기울기를 바탕으로 가중치를 업데이트하는 것이 딥러닝 학습의 핵심이다.

\`\`\`
학습 사이클: 순전파(예측) → 손실 계산 → 역전파(기울기 계산) → 가중치 업데이트
\`\`\`

---

## 2장. 최적화 알고리즘 (Optimizer)

최적화 알고리즘은 역전파로 계산된 기울기를 이용해 가중치를 어떻게 업데이트할지를 결정하는 방법이다.

**SGD (Stochastic Gradient Descent)**  
가장 기본적인 옵티마이저로 학습률이 고정되어 있어 수동 튜닝이 필요하며, 수렴이 느릴 수 있다.

**AdaGrad**  
각 파라미터마다 학습률을 개별적으로 조정한다. 자주 등장한 파라미터의 학습률은 낮추고 드문 파라미터의 학습률은 높이지만, 학습이 진행될수록 학습률이 너무 작아지는 단점이 있다.

**RMSProp**  
AdaGrad의 학습률 소멸 문제를 해결한 방법으로, 최근 기울기의 지수이동평균을 이용해 학습률을 조정한다.

**Adam (Adaptive Moment Estimation)**  
모멘텀(1차 지수이동평균)과 RMSProp(2차 지수이동평균)을 결합한 알고리즘이다. 각 파라미터마다 학습률을 개별적으로 조정하며 빠른 수렴과 안정성을 동시에 확보한다. 현재 딥러닝의 표준 옵티마이저로 가장 많이 사용된다.

\`\`\`
발전 흐름: SGD → Momentum → AdaGrad → RMSProp → Adam
\`\`\`

## 3장. 과적합과 방지 기법

### 3.1 과적합과 과소적합

**과소적합(Underfitting)**  
모델이 학습 데이터조차 제대로 학습하지 못한 상태이다. 훈련 정확도와 테스트 정확도 모두 낮으며, 모델이 너무 단순하거나 학습이 부족할 때 발생한다.

**과적합(Overfitting)**  
모델이 학습 데이터의 패턴뿐 아니라 노이즈까지 외워버린 상태이다. 훈련 정확도는 높지만 테스트/실제 데이터에서는 성능이 떨어진다.

\`\`\`
과소적합: 훈련 ↓ / 테스트 ↓  →  모델이 너무 단순
과적합:   훈련 ↑ / 테스트 ↓  →  모델이 너무 복잡하거나 데이터 부족
\`\`\`

---

### 3.2 과적합 방지 기법

**L1 규제 (Lasso)**  
가중치의 절댓값 합을 손실 함수에 패널티로 추가한다. 일부 가중치를 정확히 0으로 만드는 특성이 있어 특징 선택(Feature Selection) 효과가 있다.

**L2 규제 (Ridge / Weight Decay)**  
가중치의 제곱합을 손실 함수에 패널티로 추가한다. 가중치가 클수록 패널티가 커져 특정 가중치가 지나치게 커지는 것을 억제한다.

**드롭아웃(Dropout)**  
학습 시 매 배치마다 일정 비율의 뉴런을 무작위로 비활성화하여 특정 뉴런에 과도하게 의존하는 것을 막는다. 추론(테스트) 시에는 모든 뉴런을 활성화한다.

**데이터 증강(Data Augmentation)**  
이미지 회전, 좌우반전, 크롭 등으로 학습 데이터의 양을 늘려 과적합을 방지하는 기법이다.

**조기 종료(Early Stopping)**  
검증 데이터의 손실이 더 이상 감소하지 않고 증가하기 시작할 때 학습을 중단하는 기법이다. \`patience\` 파라미터로 몇 epoch까지 기다릴지 설정한다.

---

### 3.3 정규화 기법

**배치 정규화(Batch Normalization)**  
미니배치마다 평균을 0, 분산을 1로 정규화한 뒤 학습 가능한 스케일(γ)과 이동(β) 파라미터로 변환한다. 내부 공변량 이동(Internal Covariate Shift)을 줄여 더 높은 학습률 사용이 가능하고 수렴 속도가 빨라진다.

**레이어 정규화(Layer Normalization)**  
배치가 아닌 각 샘플의 레이어 단위로 정규화한다. RNN, Transformer 등에서 주로 사용된다.

## 4장. 합성곱 신경망 (CNN)

### 4.1 CNN 핵심 개념

합성곱 신경망(Convolutional Neural Network, CNN)은 이미지 처리에 특화된 신경망 구조이다.

**필터(Filter) / 커널(Kernel)**  
처음에는 랜덤하게 초기화되지만 역전파 학습을 통해 엣지, 텍스처, 패턴 등 유의미한 특징을 감지하도록 최적화된다.

- 초기 층의 필터: 선, 엣지, 색상 등 저수준 특징 감지
- 깊은 층의 필터: 눈, 코, 바퀴 등 고수준 특징 감지

**패딩(Padding)**  
합성곱 연산 후 출력 크기가 줄어드는 것을 방지하고 가장자리 정보를 보존하기 위해 입력 데이터의 테두리에 값을 채우는 기법이다.

- **Zero Padding:** 테두리에 0을 채움 (가장 일반적)
- **Same Padding:** 출력 크기 = 입력 크기가 되도록 패딩 크기 자동 계산
- **Valid Padding:** 패딩 없음. 출력 크기가 입력보다 작아짐

**스트라이드(Stride)**  
필터가 입력 데이터 위를 이동할 때 한 번에 건너뛰는 픽셀 수이다. Stride가 클수록 출력 크기가 작아지고 연산량이 줄어든다.

**채널(Channel)**  
입력 데이터의 깊이를 의미한다. RGB 이미지는 채널=3, 흑백 이미지는 채널=1이다.

**1×1 합성곱**  
공간 크기(H×W)는 변경하지 않고 채널 수만 조정하는 연산이다.

- 채널 수 감소(차원 축소)를 통한 연산량 감소
- 활성화 함수와 결합해 비선형성 추가
- 단, 이미지의 해상도 확대는 불가능하다.

---

### 4.2 CNN 구조

\`\`\`
입력 이미지 → [합성곱 층 → 풀링 층] 반복 → 평탄화(Flatten) → 완전 연결 층 → 출력
\`\`\`

**합성곱 층(Convolutional Layer)**  
필터를 이용해 입력 데이터에서 특징을 추출하는 층이다.

**풀링 층(Pooling Layer)**  
이미지의 중요한 특징은 유지하면서 데이터의 가로·세로 크기를 줄여 연산량을 감소시키고 위치 불변성(Translation Invariance)을 확보하는 층이다. 학습 파라미터가 없다.

- **Max Pooling:** 영역 내 최댓값 추출 (가장 일반적)
- **Average Pooling:** 영역 내 평균값 추출

**평탄화(Flatten)**  
다차원 특징 맵을 1차원 벡터로 변환하는 과정이다.

**완전 연결 층(Fully Connected Layer)**  
모든 뉴런이 연결된 층으로 최종 분류를 수행한다.

---

### 4.3 주요 CNN 모델

**AlexNet (2012)**  
ImageNet 대회 우승으로 딥러닝 부흥의 시작점이 된 모델이다. ReLU, Dropout, GPU 학습을 처음 도입했으며 8층 구조이다.

**VGGNet (2014)**  
3×3 필터만 사용해 구조를 단순하게 유지하면서 깊이를 16~19층까지 늘린 모델이다.

**GoogLeNet / Inception (2014)**  
다양한 크기의 필터를 병렬로 사용하는 Inception 모듈을 도입한 모델이다.

**ResNet (2015)**  
입력값을 출력값에 직접 더해주는 **잔차 연결(Residual Connection / Skip Connection)** 을 도입해 기울기 소실 문제를 해결하고 100층 이상의 깊은 네트워크 학습을 가능하게 한 모델이다.

---

## 5장. 재귀 신경망 (RNN)

### 5.1 RNN 기본 구조

재귀 신경망(Recurrent Neural Network, RNN)은 텍스트, 음성, 주가 등 **순차적(Sequential) 데이터**를 처리하기 위해 설계된 신경망이다.

이전 시점의 **은닉 상태(Hidden State)** 를 현재 시점의 입력과 함께 처리한다는 점이 CNN, MLP와의 핵심 차이이다.

\`\`\`
h(t) = f(h(t-1), x(t))
현재 은닉 상태 = 함수(이전 은닉 상태, 현재 입력)
\`\`\`

**은닉 상태(Hidden State)**  
이전 시점까지의 정보를 압축해 저장하는 벡터로, 매 시점마다 업데이트되어 다음 시점으로 전달된다. RNN의 **단기 기억** 역할을 수행한다.

---

### 5.2 RNN의 한계와 발전 모델

**Vanilla RNN의 한계 - 장기 의존성(Long-term Dependency) 문제**  
문장이 길어질수록 초기 단어의 정보가 소실되는 문제가 발생한다. 기울기 소실(Vanishing Gradient) 문제가 근본 원인이다.

**LSTM (Long Short-Term Memory)**  
Forget Gate, Input Gate, Output Gate와 **Cell State(장기 기억)** 를 도입해 장기 의존성 문제를 해결한 모델이다.

**GRU (Gated Recurrent Unit)**  
LSTM을 단순화한 모델로, Reset Gate와 Update Gate만 사용한다. 파라미터가 적어 학습이 빠르면서 유사한 성능을 보인다.

**Bi-LSTM (Bidirectional LSTM)**  
순방향과 역방향 LSTM을 결합한 모델이다. 문장의 앞뒤 문맥을 모두 고려할 수 있어 자연어 처리에 효과적이다.

\`\`\`
발전 흐름: Vanilla RNN → LSTM / GRU → Bi-LSTM
\`\`\`

## 핵심 용어 요약

| 용어 | 한 줄 정의 |
|------|-----------|
| 학습률(Learning Rate) | 가중치 업데이트의 보폭을 결정하는 하이퍼파라미터 |
| 배치 크기(Batch Size) | 한 번의 가중치 업데이트에 사용하는 데이터 수 |
| 에포크(Epoch) | 전체 데이터를 한 번 훑는 횟수 |
| 과적합(Overfitting) | 훈련엔 강하지만 실제 환경에서 성능이 낮아지는 현상 |
| 역전파(Backpropagation) | Chain Rule로 각 가중치의 기울기를 계산하는 알고리즘 |
| 패딩(Padding) | CNN 연산 후 출력 크기 유지를 위해 테두리에 값을 채우는 기법 |
| 스트라이드(Stride) | 필터가 한 번에 이동하는 간격 |
| 풀링(Pooling) | 특징 맵 크기를 줄여 연산량 감소 및 위치 불변성 확보 |
| 잔차 연결(Residual Connection) | 입력을 출력에 직접 더해주는 Skip Connection (ResNet) |
| 은닉 상태(Hidden State) | RNN에서 이전 정보를 요약해 전달하는 메모리 벡터 |
| 드롭아웃(Dropout) | 학습 시 뉴런을 무작위로 비활성화해 과적합 방지 |
| 조기 종료(Early Stopping) | 검증 손실 증가 시 학습을 중단해 과적합 방지 |
| Adam | 모멘텀 + RMSProp을 결합한 현재 표준 옵티마이저 |
| ReLU | f(x) = max(0, x), 현재 가장 많이 사용되는 활성화 함수 |
| 배치 정규화(Batch Normalization) | 미니배치 단위로 정규화해 학습 속도와 안정성 향상 |
